## FAQ

### What is XCutors and what does it do?

XCutors is a collection of popular Windows-based Roblox script executors and loaders packaged together. It allows you to manage and run Lua scripts within Roblox games using various supported executor tools.

### Is this safe to use?

The XCutors package itself is a management tool. However, the use of any third-party executor to run scripts in Roblox is against Roblox's Terms of Service and carries a risk of account action. Always use such tools with caution and understanding of the risks involved.

### Why are there multiple executors included?

Different executors have varying levels of performance, script compatibility, and update status. Including multiple options allows you to choose the one that works best for a particular script or game situation, or to switch if one goes offline.

### How do I update the executors?

The xcutorsLoader includes a built-in update checker. When an update for a bundled executor is available, you will be prompted through the loader's interface to download and apply it.

### What kind of scripts can I run?

You can run a wide variety of Lua scripts created for Roblox, including those that modify game behavior, automate tasks, or add visual elements. Script functionality depends entirely on the script's code and the executor's API support.

### Do I need to keep the loader running?

Yes, you need to keep xcutorsLoader.exe running in the background after injection. It manages the attached executor. Closing the loader will typically close the injected executor as well.

### Where can I find scripts to use?

Scripts are widely available from various community websites and forums. You can copy a script's code and paste it into the executor's script editor to execute it. Be mindful of script sources for safety.

### What should I do if an executor isn't working?

First, ensure Roblox is updated and try running the loader as administrator. If a specific executor fails, try switching to another one from the collection. You can also check for updates or look for announcements regarding that executor's status.
